Cloud Scanner is a modern, beautifully designed mobile application built with Flutter. It provides a seamless and visually stunning QR code scanning experience. Featuring a sleek dark mode design, ocean blue accents, and an animated laser scanning interface, it stands out as a premium scanning utility.

## 🌟 Features

*   **Sleek Dark UI:** A gorgeous, high-contrast dark theme optimized for readability and aesthetics.
*   **Animated Scanner:** An engaging animated laser line and custom scanning frame.
*   **Live Camera Scanning:** Instantly detect and read QR codes using the device camera.
*   **Gallery Import:** Scan QR codes directly from images saved in your device gallery.
*   **Torch Support:** Built-in flashlight toggle for scanning in low-light environments.
*   **Camera Switch:** Easily switch between front and rear cameras.

## 🛠️ Tech Stack

*   **Framework:** [Flutter](https://flutter.dev/)
*   **Language:** Dart
*   **Packages:**
    *   `mobile_scanner` - For high-performance camera and barcode scanning.
    *   `image_picker` - To select images from the gallery.
    *   `url_launcher` - To handle scanned URL actions.
    *   `path_provider` - For local storage solutions.

## 🚀 Getting Started

### Prerequisites
*   Flutter SDK installed (version ^3.12.0 or higher)
*   An IDE (Android Studio, VS Code, etc.) with Flutter extensions installed.

### Installation

1.  **Clone the repository** (or download the source code):
    ```bash
    git clone https://github.com/yourusername/cloud_scanner.git
    cd cloud_scanner
    ```

2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```

3.  **Run the application:**
    ```bash
    flutter run
    ```
